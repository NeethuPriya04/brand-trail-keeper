# BrandTrail
AI-assisted brand governance and content trust platform.
Keep every message on-brand. Keep every claim traceable.

Team: 404 Founder (solo) | Hackathon: Inkloom AI

## Live demo
https://brand-trail-keeper.lovable.app/login
Use the demo buttons on the login page: Continue as Manager / Creator / Reviewer.

## What it does
Checks content against versioned approved brand facts, explains each finding
with its source, and routes content to a human reviewer for approval.
